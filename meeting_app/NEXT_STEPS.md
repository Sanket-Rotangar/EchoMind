## 🎨 Customization

### To Adjust Colors:
Edit `lib/design_system/colors.dart`:
- Change `primaryAccent` for main gradient color
- Change `secondaryAccent` for secondary highlights
- Change `background` for app background

### To Adjust Animations:
- Glow pulse: 2s loop (can be adjusted in components)
- Button press: 150ms (in button components)
- Hover effects: 200ms (in BentoTile)

### To Adjust Blur:
- Glass cards: 30px blur (in GlassCard)
- Bento tiles: 30px blur (in BentoTile)
- Can be adjusted via `blur` parameter
